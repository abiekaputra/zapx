# Security policy

## Supported version

ZapX is under active portfolio development. Security fixes apply to the current `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository. Include the affected component, reproduction steps, impact, and any suggested mitigation.

You should receive an acknowledgement within seven days. A confirmed report will be assessed, fixed, tested, and disclosed with the minimum information needed to help users update safely.

## Security boundaries

ZapX is currently designed for reproducible local evaluation. It has no public deployment claim. The planned security controls, data handling, webhook protections, and threat model are documented in [the security model](docs/architecture/security-model.md).
