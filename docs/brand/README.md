# ZapX Brand System

## Mark

The ZapX mark uses two layers:

- a solid diagonal bolt that reads as a fast, angular **Z**; and
- two aligned counter-strokes that complete an **X** behind the bolt.

The interrupted counter-stroke gives the bolt visual priority and keeps the
intersection legible at navigation-icon size. Acid green remains the product's
operational signal color, while near-black connects the mark to the console.

- `zapx-logo-mark.svg` — scalable app mark
